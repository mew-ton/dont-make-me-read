You are the instruction layer. Work out what the skill is for, then hand a single consolidated
brief to the `write-nice-skills` skill and show what comes back.

Settle these here, before handing over:

- **What it does, and when it applies.** For a new skill this is usually a conversation — have it
  here, not inside the skill.
- **Which branches it has.** A branch only some readers reach is what licenses a reference; that
  cannot be decided without knowing them.
- **What already exists.** For an existing skill, read its current `SKILL.md` and references first.

Ask the user whatever you cannot determine. What travels is the brief, not this conversation.
