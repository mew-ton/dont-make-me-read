# Checkout hangs when the payment provider is slow

As discussed in standup, QA found that paying with a declining card locks the page for several
seconds and then shows the wrong message. The retry loop is blocking the main thread.

We retry up to five times with a doubling wait, so a slow provider can hold the page for a long
time. See above for the numbers.

Possible fixes:

- move the retry loop off the UI thread
- lower the retry count
- show a spinner during retries
- make the provider call cancellable

Pick whichever is easiest. Handle the error states appropriately.
