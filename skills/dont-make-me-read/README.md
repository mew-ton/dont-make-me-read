# dont-make-me-read

Holds any writing down to the range a reader has to hold in their head before they know what to do —
and stays in force while you write, because the writer is the one person who cannot feel that range.

It is the foundation the rest of this plugin is built on. Where another skill here narrows the same
test to one artifact, it says so in its own body.

It does not judge style, length, or tone, and it does not decide what an artifact should contain —
the skill that owns that artifact does.

## The way in

Install the plugin as the [root README](../../README.md) describes. There is nothing to type: this
skill is model-invoked, it fires on any writing task, and it stays in force for the rest of that task
rather than for the one response that loaded it.

## Where the rest lives

`SKILL.md` holds the range, the test that applies it, and the guards against skipping it. Start
there, not here.

## The two propositions

Nothing loads this file: it is not referenced from `SKILL.md`, so it costs the agent no context. What
follows is why the skill exists, for whoever maintains it.

Every rule in `SKILL.md` follows from these.

1. **Nobody wants to hold a lot in their head to work out what to do.** Not for beautiful text, not
   for thorough text, not for polite text.
2. **The writer cannot tell how much that is.** You read your own draft while supplying the context
   it is missing, so the range reads small to you, and only to you.

## Why this is a skill and not advice

The second proposition is the whole reason. Advice is taken by someone who can already see the
problem, and the writer cannot see this one — the draft reads fine to them, and will go on reading
fine however long they look at it.

So the judgment has to arrive from outside the moment of writing. That is what makes it a skill that
fires mid-task and stays in force for the rest of it, rather than a style guide somebody consults.

## Why the operative half is in the guard

`SKILL.md` keeps "you are supplying the intent the text is missing as you read it" in its Common
Rationalizations, because there it refutes the excuse at the moment the agent reaches for it. Stated
as a proposition it would be read once and agreed with, which is not the same thing as being applied.
