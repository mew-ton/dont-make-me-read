# Verification — a finding written as a comment

Read this before posting the finding. Each box is a budget, or a check that is settled by looking at
the finished text; the rest of the rules are met by reading them where they live.

- [ ] Title is one sentence, and stays true pointed at another instance of the same rule — or the
      site is genuinely the only instance.
- [ ] Summary is at most three short statements, one fact or one instruction each.
- [ ] Details is inside 20 lines, code blocks excluded — or absent.
- [ ] The budgets were counted in the language posted in, and the finding is in one language only.
- [ ] One edit answers the whole finding, and every part of it sits in one strength row.
