# frontmatter を書く

スキルの、あるいはサブスキルの frontmatter を設定するときに読むこと。

## What is required（必須のもの）

`name` と `description`。インストールされているすべてのスキルについて、毎ターン事前ロードされる二つである。
`name` はそのスキルを起動するための名前であり、そのスキルが置かれたディレクトリと一致する。

## What the rest settles（残りが決めること）

他のフィールドはすべて任意で、見つけられるかどうかではなく、どう走るかを決める。

| フィールド | 何を決めるか |
|---|---|
| `user-invocable`、`disable-model-invocation` | どちらの呼び出し元が到達できるか — 人の `/` メニュー、モデル、あるいは両方。到達範囲が両方でないスキルはどちらも設定すること：誰も打たないはずのスキルは `user-invocable: false`、モデルが選べなければならないスキルは `disable-model-invocation: false` |
| `context`、`background`、`model` | それ自身の実行環境として走るのか、そして何のもとで走るのか |
| `allowed-tools` | すでに手の届く範囲のうち、何がプロンプトなしで事前承認されるか |
| `disallowed-tools` | 何に手を伸ばしてはならないか — ツールを取り上げるのはこのフィールドである |

## A sub-skill's fields（サブスキルのフィールド）

親が一つのフェーズを固有の実行環境で走らせるために起動するサブスキルは、`name` と `description` に加えて次を
持つ。

```yaml
user-invocable: false
disable-model-invocation: false
context: fork
background: false
```

**`context: fork` こそが、その環境を与えるものである。** サブスキルを、親のターンの延長ではなくそれ自身の
実行環境にする。それがないと、`model` は現在のターンの残り — メインの会話 — に適用される。

**`background: false` が、答えが返るまで親のターンを留める。** 既定は `true` で、それはサブスキルが何かを
生み出す前に親へターンを返してしまう。

`user-invocable: false` と `disable-model-invocation: false` は、合わせて親を唯一の呼び出し元に保つ：ユーザーの
`/` メニューの外へ、モデルの手の届くところへ。

自分の読み手に見つけてもらう位置に置かれるサブスキル — 固有の leading word を持つから切り出されたもの — は、
このブロックを一つも取らない。これは親が走らせるフェーズのものである。

`model` はコストと能力を天秤にかけるものであり、その fork を何のために取ったかがそれを決める。収集はたいてい
**文脈**のために取られ、成果物を生むフェーズは**清浄さ**のために、どちらの複製も相手の答えに手が届かない形で
二度走らせるフェーズは**独立性**のために取られる。

| 何のために | fork が買うもの | `model` |
|---|---|---|
| **文脈** — 大量の収集がメインスレッドから外れる | 生の材料が親の文脈に一切着地しない | それができる最も安いモデル：純粋な収集と計数なら `haiku`、軽い正規化が絡むなら `sonnet` |
| **独立性** — 一つのフェーズの二つの走りが互いの出力を見てはならない | 同じフェーズが二度走り、どちらの走りも相手が生んだものに到達できない | そのフェーズが単独で取るものに従う。文脈のためか、清浄さのためか |
| **清浄さ** — 指示書を生んだ会話が成果物に届いてはならない | 探索、言いかけの依頼、取ってきた材料が、成果物を書く文脈に一切入らない | 設定しない。サブスキルは親のものを継承する |

**ツールセット**のために取る fork は、それを `allowed-tools` と `disallowed-tools` で狭める。どのスキルでも
使う、同じ二つのフィールドである。

## No comments（コメントを書かない）

そのすべてをコメントなしで書くこと。frontmatter はそのスキルが発火するたびにロードされる。その*選択*に議論が
要るフィールドが要するのは、著者が反論できる散文 — 本文 — であって、末尾の `#` ではない。設定をただ言い直す
一文は、本文が落とすものである。
