# What counts, and how to spot it（何が該当し、どう見つけるか）

パスを走らせるときに読む。下の形は、依存がページ上でどう見えるかである。その次の節は、強いものが
どう表に出てくるかで、こちらは何も抽出してくれるものがないためにある。

## The shapes（形）

| テキストが | 固定されている先 | 壊れるとき | 強さ |
|---|---|---|---|
| リンク、パス、行番号 | その場所 | 移動する | 弱 |
| issue / チケット / PR 番号 | その項目 | クローズ、移動、採番し直し | 弱 |
| 外部の出典の引用 | 他人の判断 | 相手が改訂する、または消える | 弱 |
| 散文の中で担われた名前 | その定義 | 改名、削除、意味の移動 | 強 |
| 員数、または完全だと主張された集合 | その成員 | 何かが加わる／抜ける | 強 |
| それが所有されている場所から写した定義や計画 | その所有者 | 所有者が変わり、この写しが変わらない | 強 |
| どう配置されているかについての主張 | その配置 | 再構成される | 強 |
| 翻訳、ミラー、二つ目のコピー | 原文の全体 | 原文のどこかが変わる | 強 |
| それが乗っているファイル自身についての宣言 | そのファイルの残りが述べていること | 宣言がカバーすべきものを本文が獲得する／失う | 強 |

**この一覧は閉じていない。** ここにない形でも、向こう側を直せばこちらも直さねばならないなら該当する —
その定義こそがテストであり、この表は定義のうち繰り返し現れる部分にすぎない。

## Spotting the strong ones（強いものをどう見つけるか）

強い依存は自分から名乗らない。目印を探すのではなく、文の形を読む。

- **固有名詞はすべて問いである：この名前は誰が所有しているか。** 答えが別のどこかなら、その文はその
  別のどこかに固定されている。
- **このファイルの外にあるものについての、現在形の主張はすべて** — 何をするか、何を含むか、どう
  組み立てられているか — そのものの現在の状態についての主張であり、状態が失効すれば一緒に失効する。
- **列挙はすべて。**「A と B」「三つのフェーズ」「各モジュール」：集合は、員数を言っていようがいまいが
  成員についての主張である。
- **向こう側を開いていなければ書けなかった文はすべて。** 写した定義の見分け方がこれである。書くのに
  出典を読む必要があったなら、真であり続けさせるのにも必要になる。
- **「〜に記載のとおり」「〜より」「〜と同じ」はすべて。** ポインタは弱だが、そのポインタの周りで
  その文が主張していることは、たいてい弱ではない。
- **両端が同じファイルの中にあることもある。** ヘッダが宣言し、本文が記述する。本文を編集すると、
  ヘッダだけがこのファイルのしていないことを述べたまま残りうる。ファイル境界を何も越えていないので、
  外部の何もそれを指摘しない — そしてヘッダは、本文をいじっている最中に読み返される見込みが最も低い
  部分である。

## What is not a dependency（依存ではないもの）

- その分野全体が共有している語彙。HTTP やマージコンフリクトを名指ししても、何も固定されない。
- そのページのために作った例で、外部の誰も所有していないもの — これは同時に、いま文書化している
  ツリーに対して書かれた例のほうが、そうでない例より精査に値する理由でもある。
