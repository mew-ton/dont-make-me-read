# 検証 — コメントとして書かれる指摘

指摘を投稿する前にこれを読むこと。各項目は予算であるか、仕上がったテキストを見れば決着する確認である。
残りのルールは、それが置かれている場所で読むことによって満たされる。

- [ ] Title は一文であり、同じ規則の別の事例に向けてもなお真である — あるいはその場所が本当に唯一の
      事例である。
- [ ] Summary は短い記述が最大3つ、それぞれ事実か指示のどちらか一つである。
- [ ] Details はコードブロックを除いて20行以内、あるいは存在しない。
- [ ] 予算は投稿する言語で数えられており、指摘は一つの言語だけで書かれている。
- [ ] 一つの編集で指摘全体に答えられ、そのすべての部分が一つの強さの行に収まっている。
