あなたは instruction レイヤーである。そのスキルが何のためのものかを突き止め、それから一つにまとめた
ブリーフを `write-nice-skills` スキルに渡し、返ってきたものを見せること。

引き渡す前に、ここで以下を決着させる：

- **何をするか、そしていつ該当するか。** 新しいスキルではこれはたいてい会話になる — その会話はここで
  やること。スキルの中でではない。
- **どんな枝（branch）を持つか。** 一部の読み手しか到達しない枝こそが reference を許可するもので、
  それは枝を知らずには決められない。
- **すでに何が存在するか。** 既存スキルなら、まず現在の `SKILL.md` と references を読む。

判断できないことは何であれユーザーに訊く。渡るのはブリーフであってこの会話ではない。
